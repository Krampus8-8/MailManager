# Mail Manager

Mail Manager — локальное Windows-приложение для подготовки регистрации и учёта личных аккаунтов Gmail. Интерфейс на русском языке. Регистрацию, CAPTCHA и подтверждение телефона пользователь проходит на сайте Google. Результат сохраняется после ручного подтверждения. Старые записи других сервисов доступны в разделе «Мои аккаунты».

## Запуск готовой версии

Скачайте [MailManager.exe для Windows x64](https://github.com/Krampus8-8/MailManager/releases/latest/download/MailManager.exe) и запустите его. Среда .NET Desktop Runtime входит в сборку. При первом запуске приложение создаст базу `%LOCALAPPDATA%\MailManager\mailmanager.sqlite`.

Нажмите **Обновить** в правом верхнем углу окна, чтобы проверить новую версию. Если в релизе есть патч для установленного EXE, Mail Manager скачает патч, соберёт новый EXE, проверит его SHA-256 и перезапустится. Когда готового патча нет, приложение предложит скачать полную сборку. Для закрытых релизов используется Git Credential Manager из Git for Windows.

Для сборки установите [SDK .NET 10](https://dotnet.microsoft.com/download/dotnet/10.0). Для среды разработки подойдёт Visual Studio 2026 с компонентом SDK .NET 10 и рабочей нагрузкой «Разработка классических приложений .NET». Проверьте редакцию и сборку Windows 10 или Windows 11 по [матрице поддержки Microsoft](https://learn.microsoft.com/dotnet/core/install/windows#supported-versions).

## Сборка из исходников

В Visual Studio откройте `MailManager.slnx`, дождитесь восстановления NuGet-пакетов, выберите `MailManager.App` запускаемым проектом и нажмите **F5**. Для Release измените конфигурацию решения на **Release** и выберите **Сборка → Собрать решение**.

Из PowerShell в папке проекта выполните:

```powershell
dotnet restore MailManager.slnx
dotnet run --project MailManager.App
dotnet build MailManager.slnx -c Release --no-restore
dotnet test MailManager.slnx -c Release --no-build
```

Чтобы получить автономный EXE для Windows x64, выполните:

```powershell
dotnet publish MailManager.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o artifacts/win-x64
```

Готовый файл будет в `artifacts/win-x64/MailManager.exe`. Для Windows на ARM используйте RID `win-arm64` и отдельный каталог публикации.

Для выпуска дельта-обновления передайте генератору новый EXE и оригинальные EXE версий, с которых нужно обновляться:

```powershell
dotnet run --project tools/UpdateDelta -c Release -- artifacts/v1.3.0/MailManager.exe artifacts/v1.3.0 artifacts/v1.2.3/MailManager.exe
```

Генератор проверит побайтовое совпадение восстановленного EXE с новой сборкой. Приложите полученные `MailManager-from-*.delta` к релизу GitHub вместе с `MailManager.exe`. Для каждого исходного EXE создаётся свой патч.

## Одиночная регистрация и очередь

1. Нажмите **Сгенерировать данные** или заполните поля сами. Кнопка предлагает имя, логин, пароль и пример даты рождения, если поле даты пустое. Для регистрации укажите свою дату рождения и пол. Чтобы подставить номер телефона, добавьте свой номер с плюсом и кодом страны.
2. Сохраните задачу или нажмите **Открыть регистрацию ↗**. Если задача ещё не сохранена, приложение сначала запишет её локально.
3. Воспользуйтесь расширением для Gmail или заполните поля на сайте. Если Google запросит код из SMS, введите его на сайте.
4. При успехе вернитесь в Mail Manager, проверьте фактический адрес и нажмите **Успешно**. Для одиночной задачи Gmail сохранение пароля в Mail Manager включено по умолчанию. Если пароль изменился на сайте, введите использованный пароль в поле **Другой пароль** перед подтверждением.
5. В очереди нажмите **Следующая задача**, чтобы выбрать следующую открытую задачу. Сайт откроется после отдельного нажатия.

На главной общее количество относится к сохранённым аккаунтам. Успехи, ошибки и активные задачи считаются по обоим режимам регистрации. В разделе «Мои аккаунты» можно вручную добавить уже существующий адрес.

## Автозаполнение Gmail в Chrome и Edge

1. В форме Gmail нажмите **Сохранить расширение для Chrome и Edge…**, выберите место для `GmailExtension.zip` и распакуйте его. Приложение сохраняет архив из встроенных файлов без подключения к Интернету. Архив также приложен к релизу.
2. Введите `chrome://extensions` в адресной строке Chrome или `edge://extensions` в Edge. Включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
3. В открывшемся окне выберите папку `GmailExtension`, внутри которой лежит `manifest.json`, и нажмите **Выбор папки**.
4. Откройте регистрацию Gmail. На этой вкладке нажмите значок **Mail Manager · Gmail** в меню расширений, чтобы открыть боковую панель.
5. В настольном приложении нажмите **Копировать для браузера** и вставьте данные в поле боковой панели. На каждом шаге нажимайте **Заполнить текущий шаг**, проверяйте поля и продолжайте на сайте Google.

Расширение заполняет распознанные пустые поля текущего шага: имя, фамилию, дату рождения, пол, имя пользователя, пароль с подтверждением и номер телефона. Если нужно выбрать вариант «Создать собственный адрес Gmail», выберите его на сайте и нажмите **Заполнить текущий шаг**. Данные живут в памяти панели до её закрытия, ручной очистки или истечения пяти минут. Дата рождения, пол и номер телефона не записываются в SQLite. Чтобы восстановить задачу после закрытия панели, повторно скопируйте данные из Mail Manager.

Для обновления уже установленного расширения замените файлы в папке, которую браузер загрузил как распакованное расширение, и нажмите **Обновить** на его карточке в `chrome://extensions` или `edge://extensions`.

## Импорт

Сохраните файл в UTF-8 объёмом до 256 КБ. За раз можно импортировать до 1 000 задач. CSV принимает запятую, кавычки и необязательный заголовок `provider,login`.

```csv
provider,login
Gmail,example2026
Gmail,ivan2026
Gmail,
```

В TXT укажите один логин или пару `сервис|логин` на строку.

```text
example2026
Gmail|ivan2026
Gmail|
```

Если сервис пропущен, используется Gmail. Другие сервисы при импорте не принимаются. Если логин пуст, он генерируется. Пароль для каждой задачи генерируется отдельно. Ошибка формата или локальный дубликат отменяет импорт всего файла.

## Резервные копии

В разделе «Резервные копии» выберите папку для снимка SQLite. Восстановление заменяет текущие аккаунты, задачи, историю и настройки после подтверждения и проверки копии. Для чтения паролей из копии требуется доступ к исходному профилю Windows с ключами DPAPI.

Подробности см. в [описании архитектуры](ARCHITECTURE.md) и [технической спецификации](TECHNICAL_SPECIFICATION.md).
