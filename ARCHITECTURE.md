# Архитектура Mail Manager

## Проекты

| Проект | Ответственность |
| --- | --- |
| MailManager.App | WPF, MVVM, тёмная тема, навигация, команды, диалоги, запуск браузера и буфер обмена |
| MailManager.Core | Модели, контракты хранилища и защиты секретов, правила ввода, генераторы, разбор импорта |
| MailManager.Data | EF Core, SQLite, начальная миграция, репозиторий, Windows DPAPI, снимки базы |
| MailManager.Tests | Тесты правил, генераторов, импорта, репозитория, восстановления и DPAPI |

`App.xaml.cs` создаёт зависимости, держит файловую блокировку экземпляра и запускает главное окно. `MainWindow.xaml.cs` обрабатывает только оформление и закрытие окна. Представления выбираются через WPF DataTemplate по типу ViewModel. `ShellViewModel` отвечает за навигацию, обработку ошибок, обновление общего состояния и координацию операций. Каждая страница управляет своей формой и командами.

Core не зависит от WPF и EF Core. Data реализует контракты Core. App использует оба проекта и связывает реализации при запуске.

## Данные и операции

- `EmailAccount` хранит подтверждённый или вручную добавленный адрес, сервис, статус, дату, итог проверки телефона и примечание. В поле пароля хранится DPAPI-блок.
- `RegistrationTask` хранит режим, сервис, логин, статус, метки времени и итог проверки. Для открытой задачи пароль защищён DPAPI. Задача Gmail также может хранить имя и фамилию. Дата рождения, пол и номер телефона для автозаполнения живут в памяти открытой формы и панели расширения.
- `HistoryEntry` хранит тип локального события и краткий идентификатор. Пароли, примечания и тексты внутренних исключений в журнал не попадают.
- `AppSettings` хранит одну строку с длинами по умолчанию и таймером очистки буфера.

У каждой операции репозитория собственный DbContext. Операции последовательно проходят через SemaphoreSlim и выполняются вне потока интерфейса, поскольку провайдер SQLite выполняет ввод-вывод синхронно. Результат регистрации, аккаунт и запись журнала сохраняются одной транзакцией. При закрытии задачи пароль удаляется из задачи. При успехе приложение переносит зашифрованный блок в аккаунт, если пользователь выбрал это в форме.

Начальная миграция создаёт таблицы, индексы и идентификатор формата базы. Приложение применяет миграции при запуске. Восстановление создаёт временный SQLite-снимок исходного файла, проверяет идентификатор, последовательность миграций и целостность. Если снимок создан предыдущей версией, приложение обновляет временную копию и переносит её в рабочую базу через SQLite Backup API.

## Защита данных

Режим DPAPI CurrentUser связывает зашифрованные пароли с профилем Windows. Временные байтовые буферы, создаваемые при обработке пароля, обнуляются после использования. Сгенерированные пароли существуют в памяти до очистки формы или завершения процесса.

Если пользователь копирует пароль, приложение передаёт его непосредственно в буфер Windows с форматом исключения из истории и синхронизации. Очистка по таймеру сверяет номер версии буфера, чтобы не стирать текст, скопированный позднее. При закрытии приложения выполняется попытка немедленной очистки. Другие приложения с доступом к буферу могут читать его до очистки.

Адреса, примечания, история и настройки хранятся в обычных полях SQLite. Открытие ссылки регистрации передаёт браузеру только постоянный HTTPS-адрес сервиса.

Расширение Chrome и Edge заполняет поля только по нажатию пользователя на вкладке регистрации `accounts.google.com`. Оно принимает данные после явной вставки из буфера и держит их в памяти боковой панели до пяти минут. Расширение обращается только к верхнему документу проверенной вкладки и заполняет только пустые распознанные поля.

Проверка обновлений запускается кнопкой в окне. Mail Manager запрашивает последний релиз через GitHub API без авторизации. При закрытом доступе он получает токен через Git Credential Manager. Приложение сверяет размер и SHA-256 файла с релизом. Проверенный EXE работает помощником обновления. Он ждёт завершения открытого окна, заменяет EXE в той же папке, запускает новую сборку и держит предыдущий файл до подтверждения запуска.
